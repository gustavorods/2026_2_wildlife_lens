# Olhar Selvagem

[English](README.md) | [Português (Brasil)](README.pt-BR.md) | [Español](README.es.md)

**Tagline:** Record animal sightings and organize your photos in a personal gallery.

## Description

Take a photo of an animal or choose one from your gallery, then save the sighting with its date and location. Built with React Native, Expo, and TypeScript for Android and Web. Records are stored locally on your device or in your browser.

## Installation

```bash
git clone https://github.com/gustavorods/2026_2_wildlife_lens.git
cd 2026_2_wildlife_lens
npm install
npm run start
```

In the Expo terminal, press `a` to open the Android app or `w` to open it in a browser.

## Usage

1. Open **Novo registro** (New record) and take a photo or choose an image.
2. Allow location access and review the sighting details.
3. Tap **Salvar registro** (Save record).
4. Open the sighting in the gallery to see its photo, date, and location.
