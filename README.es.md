# Olhar Selvagem

[English](README.md) | [Português (Brasil)](README.pt-BR.md) | [Español](README.es.md)

**Lema:** Registra avistamientos de animales y organiza tus fotos en una galería personal.

## Descripción

Fotografía un animal o elige una imagen de la galería y guarda el registro con su fecha y ubicación. Desarrollado con React Native, Expo y TypeScript para Android y Web. Los registros se almacenan localmente en el dispositivo o navegador.

## Instalación

```bash
git clone https://github.com/gustavorods/2026_2_wildlife_lens.git
cd 2026_2_wildlife_lens
npm install
npm run start
```

En la terminal de Expo, pulsa `a` para abrir la aplicación en Android o `w` para abrirla en el navegador.

## Uso

1. Abre **Novo registro** (Nuevo registro) y toma una foto o elige una imagen.
2. Permite el acceso a la ubicación y revisa los datos del registro.
3. Pulsa **Salvar registro** (Guardar registro).
4. Abre el registro en la galería para ver la foto, la fecha y la ubicación.
